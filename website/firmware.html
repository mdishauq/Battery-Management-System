Firmware Walkthrough

This page explains the firmware architecture, DMA-driven ADC, integration math, and the protection logic.

ADC + DMA

The ADC is configured in continuous scan of two channels and DMA writes each conversion into a 2-element buffer. The CPU reads these values and computes metrics without blocking.

// pseudo-init
HAL_ADC_Start_DMA(&hadc1, (uint32_t*)adc_buffer, 2);
// adc_buffer[0] -> voltage sample
// adc_buffer[1] -> current sample (post-amp)

Computations

Instantaneous power and integrations are computed using delta time. Formulas:

Power: $P = V_{bat} \cdot I_{bat}$

Energy accumulation (Wh): $$E_{wh}\;+=\;P\;\times\;\frac{\Delta t}{3600}$$

// example loop
float delta_s = compute_delta_seconds();
float V = adc_to_voltage(adc_buffer[0]);
float I = adc_to_current(adc_buffer[1]);
float P = V * I;
E_wh += P * (delta_s / 3600.0f);
Q_ah += I * (delta_s / 3600.0f);

Protection Logic

Overcurrent detection is evaluated several times per second. If the threshold is exceeded, the MOSFET gate is cleared immediately.

if (I > OVERCURRENT_THRESHOLD){
  HAL_GPIO_WritePin(MOSFET_GATE_GPIO_Port, MOSFET_GATE_Pin, GPIO_PIN_RESET);
  // optionally log to flash or display error
}
