System Architecture

Closed-Loop Architecture

Power Source: Main battery pack supplies the load. Sensing: Voltage divider & shunt resistor condition analog signals. Acquisition: ADC with DMA continuously streams 2 channels to RAM. Processing: STM32F103 computes instantaneous metrics (V, I, P) and integrates energy/charge over time. Display: SSD1306 OLED via I2C shows real-time dashboard. Protection: IRLZ44N MOSFET acts as solid-state contactor, breaking circuit in microseconds if safety threshold is breached. Complete cycle optimized for real-time performance and fail-safe operation.

Hardware Design

Discrete Analog Front-End

Every component is visible and tunable. No black-box modules — pure signal conditioning engineered from first principles.

Voltage Sensing (Resistor Divider)

Why: Car batteries and large battery packs (12V+) far exceed the STM32 ADC maximum of 3.3V. A passive voltage divider safely scales down the high voltage to the microcontroller's safe range.

How: Two precision resistors form a divider network. The battery voltage input is dropped across these resistors before entering ADC_CHANNEL_0. The firmware then multiplies the scaled ADC reading by the divider ratio to reconstruct true battery voltage.

Vbat = Vadc × (Rtop+Rbottom)/Rbottom

Implementation: High-tolerance resistors (1% metal film) ensure measurement accuracy. The divider ratio is pre-calculated and stored as a firmware constant for fast computation.

Current Sensing (Shunt + Op-Amp)

Why: Direct current measurement is impossible for an MCU. Instead, we measure the tiny voltage drop across a known resistance (Ohm's Law: V = I × R).

Components:

  • Shunt Resistor (0.15Ω): Low-value, high-precision resistor in series with the load. At 1A current, it drops only 0.15V, minimizing power loss while remaining measurable.
  • Op-Amp (MCP6002): Ultra-low-noise amplifier with 50× gain. The tiny 0.15V signal is amplified to a level the 12-bit ADC can resolve accurately (~7.5V at 1A).

Circuit Logic: Load current flows through shunt → voltage drop occurs → op-amp amplifies signal with gain of 50 → amplified voltage fed into ADC_CHANNEL_1.

I = Vadc / (Gain × Rshunt) = Vadc / (50 × 0.15)

Implementation: The MCP6002 is configured in non-inverting amplifier topology with feedback resistor network setting gain to exactly 50×. Decoupling capacitors near power pins minimize noise.

Solid-State Load Switching (IRLZ44N MOSFET)

Why: Traditional mechanical relays are slow (10-100 ms) and wear out over time due to contact arcing. A solid-state MOSFET provides microsecond-level switching with no mechanical wear.

Component: IRLZ44N — Logic-level N-Channel MOSFET. The key advantage is its low gate voltage threshold (1.5V typical), allowing direct 3.3V MCU GPIO drive without additional level shifting.

Fail-Safe Design: The MOSFET gate includes a physical 10kΩ pull-down resistor connected directly to Ground. This ensures that if the MCU resets or loses power, the gate potential naturally bleeds to 0V, turning the MOSFET off and disconnecting the load. No software can override this hardware safety feature.

Operation: The STM32 GPIO PA8 (push-pull output) actively drives the gate HIGH (3.3V) to turn the motor ON and LOW (0V) to turn it OFF. Protection logic evaluates current every 200ms. If overcurrent (>0.6A) is detected, the firmware de-asserts PA8, and the MOSFET switches off in microseconds.

Advantage Over Mechanical: No arcing → no contact wear → system can auto-recover from transient faults or lock out based entirely on firmware logic.

Firmware Implementation

DMA-Driven ADC Acquisition

Why: Regular ADC polling blocks the CPU, wasting processing cycles waiting for conversions. Direct Memory Access (DMA) solves this by letting the ADC and a dedicated DMA controller handle data transfers autonomously.

How: The ADC is configured in continuous scan mode sampling two channels (Voltage on CH0, Current on CH1). Every conversion completes, the DMA controller automatically writes the result to a 2-element buffer in RAM. The CPU reads this buffer whenever needed — no blocking, no waiting.

Benefit: Real-time responsiveness. While the ADC continuously acquires data, the firmware is free to process math, update the display, and evaluate safety conditions without interruption.

// Initialize ADC with DMA
HAL_ADC_Start_DMA(&hadc1, 
  (uint32_t*)adc_buffer, 2);

// Main loop reads pre-filled buffer
uint32_t v_adc = adc_buffer[0];
uint32_t i_adc = adc_buffer[1];

Real-Time Data Processing

Integration Strategy: Instantaneous power is calculated from voltage and current. Energy and charge are accumulated over time using timestamped deltas to integrate power and current.

Formulas:

// Instantaneous values
P_watts = V_battery * I_battery

// Accumulate energy (Watt-hours)
E_wh += P_watts * (delta_t / 3600)

// Accumulate charge (Amp-hours)  
Q_ah += I_battery * (delta_t / 3600)

// State of Charge
SoC_percent = (Q_ah / Q_capacity) * 100

Time Delta: Each loop iteration, the firmware calculates elapsed seconds since the last update. This delta (typically 200ms) allows accurate integration regardless of processing speed variations.

Active Protection Logic

Architecture: Protection runs 5 times per second (200ms intervals). If current exceeds 0.6A threshold, the firmware immediately de-asserts GPIO PA8, turning off the MOSFET and disconnecting the load in microseconds.

Why Discrete Logic Over IC: Standard automotive BMS ICs (like Texas Instruments or NXP variants) handle protection internally and report only final status. Building protection in firmware gives complete transparency: you see exactly which condition triggered, can log it, and implement custom recovery strategies.

// Protection evaluation (runs every 200ms)
if (I_battery > OVERCURRENT_THRESHOLD) {
  HAL_GPIO_WritePin(MOSFET_PORT, 
    MOSFET_PIN, GPIO_PIN_RESET);
  fault_flag = 1;
  log_fault_event();
}

Custom Recovery: The system can be programmed to auto-retry after a brief timeout, or lock out permanently based on fault count.

Fail-Safe Architecture

Design Philosophy: Power must be actively maintained. If anything fails (software crash, watchdog reset, loss of power), the system defaults to a safe OFF state.

Mechanisms:

  • Physical Pull-Down: 10kΩ resistor on MOSFET gate → Ground guarantees gate discharges to 0V even if MCU is unpowered.
  • Watchdog Timer: Hardware watchdog monitors firmware health. If watchdog isn't fed (software hangs), it triggers a reset. Gate pull-down ensures MOSFET stays off during reset.
  • No Arcing: Solid-state switching means no mechanical contacts → no arcing → no wear → system remains reliable indefinitely.

HAL_IWDG_Refresh(&hiwdg);
