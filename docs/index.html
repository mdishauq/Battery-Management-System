Custom Battery Management System

Real-time sensing, DMA-driven acquisition, and microsecond-level protection — designed with discrete analog front-ends and STM32 firmware.

Explore Architecture Watch Demo

Executive Summary

This project implements a custom BMS around the STM32F103 MCU with a discrete analog front-end for voltage and current sensing, an SSD1306 OLED UI, and a solid-state MOSFET disconnect. It emphasizes education and transparency instead of black-box sensors.

System Architecture

The architecture follows a closed-loop: precise analog sensing → real-time DMA acquisition → numerical processing → OLED display and safety protection. Key components are listed below.

  • Sensing: Voltage divider for pack voltage; low-value shunt resistor with op-amp for current.
  • Acquisition: ADC configured in continuous scan of two channels with DMA into a 2-sample buffer.
  • Processing: STM32F103 (Cortex-M3) computes instantaneous power and integrates energy/charge using delta-time.
  • Display & UI: SSD1306 128×64 via I2C presents formatted metrics and status.
  • Protection: IRLZ44N low-side MOSFET controlled by GPIO with physical pull-down for fail-safe off-state.

Key Features

High-accuracy measurements and robust software protection make this design ideal for education and small-scale power applications.

  • ADC resolution: 12-bit (4096 steps) with carefully chosen divider/gain scaling.
  • Shunt resistor: 0.15Ω with op-amp gain ≈50 for measurable ADC input.
  • Real-time computed metrics: V, I, P = V×I, E (Wh), Q (Ah), SoC%.

Hardware & Circuit Design

This project intentionally uses discrete analog components so every signal path is visible and tunable. Below are the main circuit blocks and their roles.

Voltage Sensing

A precision resistor divider scales the pack voltage down to the MCU's ADC input range. The firmware reconstructs the real battery voltage by applying the divider ratio to ADC readings. Example formula used in firmware:

V_{bat} = V_{adc} \times \frac{R_{top}+R_{bottom}}{R_{bottom}}

Current Sensing

The load current is measured across a low-value shunt resistor (0.15Ω). Because the voltage drop is small, an op-amp with gain (~50×) amplifies the signal before the ADC. Firmware back-calculates:

I = \frac{V_{adc}}{Gain \times R_{shunt}}

Solid-State Switching & Safety

An IRLZ44N logic-level MOSFET is used as a low-side switch. The gate is held to ground via a pull-down resistor so that on reset or power loss the MOSFET stays off. The MCU drives the gate actively for normal operation and immediately releases it when a fault is detected.

// ADC Channel mapping
ADC_CHANNEL_0 = Voltage
ADC_CHANNEL_1 = Current (amplified)

// Example protection condition
if (I > 0.6) { // amps
  MOSFET_GATE = OFF; // immediate disconnect
}

Firmware & Software

The firmware is written in C using the STM32 HAL. ADC is configured in continuous scan mode across two channels and DMA transfers conversion pairs into a small memory buffer. This minimizes CPU blocking and guarantees deterministic sampling behavior.

DMA-Driven ADC

ADC samples are streamed into `adc_buffer[2]` via DMA. The main loop reads the latest values without polling the ADC peripheral directly.

Data Processing

Instantaneous power and integrated energy/charge are computed using the elapsed time between iterations:

// instantaneous power
P = Vbat * I

// energy (Wh) accumulation over delta seconds
E_wh += P * (delta_s / 3600.0);

// charge (Ah)
Q_ah += I * (delta_s / 3600.0);

Safety & Watchdog

The system evaluates safety thresholds several times per second. If an overcurrent or unexpected condition is detected, the firmware immediately clears the MOSFET gate and can log the event to non-volatile storage or display an error on the OLED. A watchdog timer is used to ensure fail-safe recovery; if the MCU locks, the pull-down resistor keeps the MOSFET off.
