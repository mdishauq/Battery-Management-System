Hardware Design

Discrete Analog Front-End

Every component is visible and tunable. No black-box modules — pure signal conditioning engineered from first principles.

Voltage Sensing

Precision resistor divider scales battery voltage to ADC range.

Vbat = Vadc × (Rtop+Rbottom)/Rbottom

Current Sensing

Low-ohm shunt with op-amp amplification for accurate readings.

I = Vadc / (Gain × Rshunt)

Backside assembly showing soldering and wiring

Firmware Implementation

DMA-Driven ADC

ADC continuously samples channels, DMA transfers data to buffer automatically.

HAL_ADC_Start_DMA(&hadc1, 
  (uint32_t*)adc_buffer, 2);

Data Integration

Accumulate energy and charge using timestamped deltas.

E_wh += P × (Δt / 3600)
Q_ah += I × (Δt / 3600)

Protection Logic

Evaluate thresholds multiple times per second, disconnect immediately on fault.

if (I > 0.6A) {
  MOSFET_GATE = OFF;
}

Fail-Safe Design

Physical pull-down resistor guarantees safe power-off state on MCU reset.

// Default OFF state
// Watchdog ensures recovery
// No arcing, no wear
